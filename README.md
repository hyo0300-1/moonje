# 국어 스튜디오 (시연판)

설계서 v2의 1단계 구현입니다. 설치 없이 브라우저에서 동작합니다.

## 여는 방법
- `국어스튜디오.html` 하나만 더블클릭 (인터넷 연결 필요: OCR·PDF 모듈을 CDN에서 불러옴)
- 또는 이 폴더를 GitHub 저장소에 올리고 GitHub Pages로 배포 (`index.html` 기준)

## 아직 서버 단계인 것
- AI 문항 생성·풀이 검증, 구조도 생성, 첨부자료-지문 정렬, API 키·MCP
- 데이터는 이 브라우저(IndexedDB)에만 저장 → Supabase 스키마(`../supabase/migrations`)로 옮길 예정
- 전용 OCR은 시연용 Tesseract(브라우저 안). 서비스에서는 Upstage/CLOVA 등으로 교체

## 개발 서버로 테스트하기
1. `kor-studio` 폴더에서 **`개발서버 시작.cmd`** 를 더블클릭
2. 브라우저가 `http://127.0.0.1:5178` 로 자동으로 열림
3. `js/`, `css/`, `index.html` 을 고쳐 저장하면 열린 화면이 1초 안에 자동 새로고침
4. 끄려면 검은 창에서 `Ctrl + C`

터미널을 쓰면: `cd kor-studio` 후 `npm run dev` (또는 `node dev-server.js`). 포트를 바꾸려면 `set PORT=5200` 후 실행.
